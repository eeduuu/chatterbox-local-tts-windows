# Voces

Esta carpeta se utiliza para guardar las voces de referencia de Chatterbox.

## Voz predeterminada

Si quieres utilizar una voz predeterminada desde el lanzador, coloca aquí un archivo llamado:

```text
voz_predeterminada.mp3
```

La estructura local quedará así:

```text
voces/
├── README.md
└── voz_predeterminada.mp3
```

`voz_predeterminada.mp3` está excluido mediante `.gitignore`, por lo que no debe subirse a GitHub.

También puedes seleccionar manualmente otro archivo `.mp3` o `.wav` desde el lanzador sin guardarlo en esta carpeta.

Utiliza únicamente voces propias o voces para las que tengas permiso.
