# Voces

Esta carpeta se utiliza para guardar las voces de referencia de Chatterbox.

Coloca aquí tus archivos `.mp3` o `.wav` con el nombre que quieras.

Al ejecutar `Generar voz.bat`, después de elegir el guion se abrirá esta carpeta para que selecciones la voz.

Los audios de esta carpeta están excluidos mediante `.gitignore`, por lo que no se suben a GitHub.

Utiliza únicamente voces propias o voces para las que tengas permiso.
